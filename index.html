Notes that think, even off the grid.

FieldNotes AI is built for the people who keep the world running where the signal doesn't reach — field technicians, drivers, farmers, surveyors, students. Capture a note anywhere. Short notes are summarised on your device by Gemini Nano: private, free, and fully offline. Long documents are handed to Gemini in the cloud for a deep summary. One app, both brains — routed automatically by Firebase AI Logic hybrid inference.

▣

Short note → On-device

Summaries & action items run on Gemini Nano in Chrome. Nothing leaves the device, it costs nothing, and it works with no connection at all.

☁

Long document → Cloud

Reports that would overflow a small on-device model go straight to cloud Gemini for a structured deep summary: overview, key facts, risks, next steps.

⇄

Fallback → Automatic

No on-device model? No problem. Firebase AI Logic falls back to the cloud seamlessly — and every AI result is badged with where it actually ran.

Your notes are stored locally first. With a Firebase project connected, they also sync to Firestore and the AI features run live.

Built with Firebase AI Logic hybrid inference — getGenerativeModel(ai, { mode: InferenceMode.PREFER_ON_DEVICE }) for short notes, ONLY_IN_CLOUD for long documents. The badge on every result comes from response.inferenceSource, reported by the SDK itself. On-device inference needs Chrome 139+ on desktop with Gemini Nano. Notes are local-first (localStorage) with optional Firestore sync.
